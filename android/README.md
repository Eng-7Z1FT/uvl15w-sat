# تطبيق أندرويد (UVL-15W سات)

تطبيق Trusted Web Activity يفتح https://eng-7z1ft.github.io/uvl15w-sat/ داخل Chrome، فالبلوتوث العادي (BLE) وبلوتوث الكلاسيك (SPP) يشتغلون مثل الموقع.

- البناء: GitHub Actions (`.github/workflows/android.yml`) مع كل تعديل في هذا المجلد، أو يدوياً من Actions.
- التوقيع: السر `ANDROID_KEYSTORE_B64` (المفتاح نفسه ما يُرفع للمستودع أبداً).
- التحميل: صفحة Releases، الإصدار `app-latest`، الملف `uvl15w-sat.apk`.
