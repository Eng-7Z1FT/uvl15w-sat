# إضافة الشخصية للفيديو تلقائياً

السكربت يحلل الفيديو، ويختار حركة الشخصية حسب الكلام، ويحرك الفم على صوتك، وبعدها يركّب الشخصية على الفيديو.

## الاستخدام

```bash
python3 process.py my_video.mp4 --srt captions.srt      # يطلع my_video_7z1ft.mp4
python3 process.py my_video.mp4 --side right --size 0.45
python3 process.py my_video.mp4 --srt captions.srt --alpha   # ومعها نسخة شفافة .mov للمونتاج
```

| الخيار | الوظيفة |
|---|---|
| `--srt` | ملف الكابشن (من CapCut أو Premiere). منه يعرف السكربت وش قلت ويختار الحركة على أساسه |
| `--side left/right` | الجهة اللي تطلع فيها الشخصية |
| `--size 0.42` | طول الشخصية نسبةً لطول الفيديو |
| `--alpha` | يطلّع كمان ملف `_character.mov` بخلفية شفافة (ProRes 4444) |
| `--plan file_plan.json` | يعيد التصدير بعد ما تعدّل الحركات يدوياً |

إذا ما فيه ملف `--srt` ومكتبة `faster-whisper` مثبتة، السكربت يفرّغ الكلام بنفسه. وإذا ما توفر لا هذا ولا هذا، يوزع الحركات حسب إيقاع الكلام فقط.

## كيف يختار الحركة

| الحركة | أمثلة على الكلمات |
|---|---|
| wave | السلام عليكم، هلا، حياكم، مع السلامة |
| celebrate | نجحت، تمت، الحمد لله، اشتغل، ممتاز |
| shocked | انتبه، احذر، مشكلة، غلط، لا تفصل |
| key | مفتاح، ريموت، سيارة، ايموبلايزر |
| typing | برمجة، برنامج، كمبيوتر، كيبل، تعريف |
| thinking | ليش، كيف، سؤال، أو أي جملة فيها علامة ؟ |
| point | شوفوا، لاحظوا، هنا، جهاز، تردد، TYT |
| talk / point | باقي الكلام |

الكلمات موجودة في `RULES` داخل `process.py`، وتقدر تضيف عليها. كل تشغيل يطلّع ملف `*_plan.txt` تراجع فيه الحركات، وملف `*_plan.json` تعدّل فيه أي حركة وتعيد التصدير بـ `--plan`.

## المتطلبات
Python 3 مع numpy، و Node.js مع playwright، و ffmpeg.
